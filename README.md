# SpotifyTF

Proyecto final del curso de **Algoritmos y Estructuras de Datos**, en el que se desarrolló una aplicación inspirada en Spotify para aplicar las estructuras de datos y algoritmos aprendidos durante el curso.

El sistema permite gestionar y explorar canciones mediante estructuras avanzadas como árboles, tablas hash y grafos, además de utilizar algoritmos de búsqueda, recorrido y ordenamiento.
